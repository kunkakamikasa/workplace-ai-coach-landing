# Workplace AI Coach — Landing

Mobile-first Next.js 14 landing page for Workplace AI Coach (iOS app).

## Stack
- Next.js 14 (App Router) + TypeScript
- Tailwind CSS
- GA4 (`NEXT_PUBLIC_GA4_ID`) with section impressions and CTA tracking

## Local
```
npm install
npm run dev
```

## Env
- `NEXT_PUBLIC_GA4_ID` — GA4 measurement id
- `NEXT_PUBLIC_APP_STORE_URL` — App Store link (optional, defaults to placeholder)

## Deploy
Auto-deployed via Vercel on push to `main`.
